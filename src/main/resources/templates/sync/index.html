Sync employee information from database to a specific device

Push All Employees to Device

Sync all active employees from database to a specific device

This will push 0 employees to the selected device.
Pull Attendance from Device

Manually sync attendance records from device to database

Note: Automatic sync is already running in the background. Use this only for immediate sync needs.
Sync Information
  • Push Employee to Device: Uploads a single employee's information (ID, name, card number) to the selected device
  • Push All Employees: Uploads all active employees from the database to the selected device
  • Pull Attendance: Downloads new attendance records from the device to the database
  • Automatic Sync: The system automatically pulls attendance data every minute from all active devices
